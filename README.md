# Horizon: Пепел Рубежа (Horizon RP)

Полноценная мобильная **2D Action-Survival RPG** для Android (HTML5 Canvas 2D + WebAudio + Capacitor 6), созданная для плавной работы даже на бюджетных смартфонах.

Все готовые установочные файлы `.apk` автоматически собираются через GitHub Actions и публикуются в разделе релизов:
👉 **[Открыть Releases и скачать последний APK](https://github.com/kotovviktor542-hub/Horizon-RP/releases)**

## 🎮 Особенности игры

- **Большой бесшовный открытый мир (`4800 × 4800`) из 5 биомов**:
  1. **Изумрудная Пустошь** (мирный Лагерь Рубежа, наставники, стартовые ресурсы и звери)
  2. **Багровые Руины** (древние колонны, ловушки с шипами, нежить и босс Морграт)
  3. **Ядовитые Топи** (кислотные болота, споровые хищники и Королева Роя Ксилла)
  4. **Морозный Пик** (снега, мифриловые жилы, ледяные маги и Колосс Валькор)
  5. **Разлом Горизонта** (обсидиан, лавовые трещины и финальный босс Азариэль)
- **Динамическая 2.5D боёвка и прыжки**:
  - Полноценная ось высоты `Z`: перепрыгивайте ударные волны боссов, шипы, кислотные лужи и каменные плиты на воде!
  - **6 видов оружия** с разной механикой и заточкой от `+1` до `+10` (*Клинок Странника, Парные Кинжалы Тени, Лук Штормового Ветра, Боевой Молот Титана, Посох Звёздного Пламени, легендарная Коса Горизонта*).
  - **3 прокачиваемые способности** (*Вихрь Пламени, Громовой Прыжок, Эфирный Бастион с вращающимися клинками*).
- **Выживание, Ремесло и Развитие**:
  - Смена дня и ночи (`+30% XP` ночью), система тонуса/сытости, добыча дерева, трав, железа, мифрила, кристаллов и эссенций душ.
  - 15 рецептов алхимии и кузнечного дела, 5 видов брони и 8 уникальных реликвий.
  - Распределение очков характеристик (*Сила, Живучесть, Ловкость, Мастерство Эфира*).
- **4 секретные локации, задания и 16 достижений**:
  - Разрушаемая рунная стена в Склепе Руин, прыжки по плитам на Остров Светлячков, загадка с 3 жаровнями у Монолита Предтеч и Тайник Алхимика.
  - Сюжетная линия, бесконечные контракты Охотника, карта мира с туманом войны и быстрым перемещением по кострам.
- **Оптимизация для слабых телефонов**:
  - Предварительно запечённый спрайтовый атлас, пространственное разбиение препятствий `O(1)`, пул частиц без пауз сборщика мусора и 3 профиля графики (*Низкое / Среднее / Высокое*).
  - Полная работа **офлайн** (процедурный WebAudio-синтезатор звуков и музыки, сохранение в память устройства).

## 🚀 Локальный запуск и проверка

```bash
npm install
npm test        # запуск автотестов игрового движка
npm run serve   # запуск веб-сервера на http://0.0.0.0:3000
```
