# VEXMORA 3D «ГЛОБАЛЬНОЕ 3D-ОБНОВЛЕНИЕ»

Полноценная мобильная **3D Action-Survival RPG** для Android на **three.js** (three r187, вендорен в `www/vendor/three`) + Capacitor 6. Вся прежняя игра — карта 6400×6400, биомы, 48 врагов, 23 босса, 31 оружие, транспорт, база, спасение выживших, квесты, крафт и магазины — перенесена 1-в-1 и теперь работает в объёме. Если устройство не поддерживает WebGL, игра автоматически запускается в классическом 2D-режиме: прогресс, баланс и сохранения общие (тот же ключ сохранения, тот же appId/подпись — обновление ставится поверх прежней версии).

## 🧊 Что нового в 3D-обновлении

- **Объёмный мир целиком**: тот же континент 6400×6400, но с высотами и рельефом — леса, горы, ущелья, пустыни, снега, болота и мегаполис. Чанковый ландшафт с LOD (3 уровня), тысячи деревьев, кустов и скал через `InstancedMesh`, объёмная вода с волнами и бликами.
- **Свет, тени и погода**: солнце и луна по дуге, 9 ключевых состояний неба, мягкие тени, туман, звёздное небо; ясно, дождь, гроза с молниями, снег и туман влияют на освещение и видимость.
- **Герой и бой**: модель с иерархией костей (таз, грудь, плечи, бёдра, голени, стопы, плащ), анимации бега, ходьбы, прыжка, блока, урона, смерти и комбо из трёх ударов. В руке меняются клинки, топоры, копья, кинжалы, луки и посохи; на модели видны шлем, нагрудник и плащ. Новая механика — **тяжёлый удар по площади** (24 стамины, дуга ×1.35, урон ×1.85, отбрасывание ×1.8; для дальнего боя — 3 снаряда веером).
- **Все 48 врагов и 23 босса** получили процедурные 3D-модели восьми типов (гуманоид, зверь, призрак, голем, элементаль, дрон, колосс, насекомое) с анимацией, боссы крупнее и со свечением.
- **Эффекты**: след клинка, искры и кровь попаданий, магические вспышки, кольца ударных волн, числа урона, пыль из-под ног.
- **3D-интерфейс**: стик, свайп камеры, кнопки атаки/тяжёлой атаки/прыжка/рывка/блока/взаимодействия, мини-карта с компасом.
- **Адаптивная графика**: 4 пресета качества (низкий/средний/высокий/ультра: тени 512–4096, текстуры 128–1024, pixelRatio 0.75–2, радиус прорисовки 3–6 чанков) с автоподбором под устройство, автоснижением при падении FPS и полным отключением в пользу 2D при ошибке 3D-движка.
- **Тесты**: `npm test` запускает 28 проверок движка и 51 проверка 3D-сцен, моста и адаптивного разрешения «движок ↔ 3D» — без WebGL, на SVGRenderer и настоящем `GameEngine`.

## 🚀 Локальный запуск и проверка

```bash
npm install
npm test            # 28 проверок движка + 51 проверка 3D-сцен, моста и адаптивного разрешения
npm start           # веб-сервер превью на http://0.0.0.0:3000
```

3D-режим можно отключить принудительно: добавьте `?mode=2d` к адресу или выберите «2D» на экране совместимости.

Управление: виртуальный джойстик (полный наклон — бег), кнопки ОГОНЬ/ПРЫЖОК/Рывок/Граната/Аптечка/Перезарядка, навыки 1–6; клавиатура WASD + Shift, Пробел, K/L/G/R/Q/E/H, способности на клавишах 1–6.
