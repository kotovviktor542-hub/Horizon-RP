# VEXMORA — БОЛЬШОЕ ОБНОВЛЕНИЕ ИГРЫ

Полноценная мобильная **2D Pixel-Art Action-Survival RPG** для Android (HTML5 Canvas 2D + WebAudio + Capacitor 6), оптимизированная для слабых смартфонов. Это расширение существующей игры: сохранены пиксель-арт стиль, управление, мир, прогресс и сохранения (тот же ключ сохранения и тот же Android appId/подпись — обновление ставится поверх прежней версии).

- **16 уникальных типов врагов** с собственным ИИ: ближний бой, стрелки, снайперы с лазерным прицелом, быстрые бегуны с рывком, прыгающие мутанты, бронированные щитоносцы (-35% урона), гренадёры, огнемётчики (взрыв при гибели), невидимые охотники, кислотные мутанты, летающие дроны, вражеские медики (лечат отряд) и 2 мини-босса охраны.
- **10 многофазных боссов с аренами**: Механический Разрушитель, Король Мутантов, Бронированный Командир (силовой щит), Снайпер-Охотник, Гигантский Зверь, Безумный Учёный, Теневой Убийца (телепорты), Огромный Боевой Робот, Генерал Армии и финальный **АРХОНТ VEXMORA**. Фазы 1/2/3, красные зоны предупреждения, награды-оружие, коллекция боссов и открытие территорий.
- **Арсенал из 24 видов оружия**: ножи/мечи/катана, лук и арбалет, пистолеты и револьвер, 3 ПП (включая плазменный), 2 дробовика, 3 винтовки (очередями и лазерная), снайперка и рельсотрон, пулемёт и миниган, гранатомёт, ракетница, Тесла-пушка с цепной молнией и эфирный излучатель. Магазины, перезарядка (кнопка/R), постепенное открытие по тирам, прокачка +10 и **5 модификаций** (коллиматор, магазин, бронебойный ствол, крио, вампир-реактор).
- **Спасение 10 NPC и выживших**: клетки с сигнализацией и охраной, защита раненых от волн, сопровождение караванов в Убежище, спасение на время (45–50 сек.), Ключ-карты и мини-боссы Надзиратели.
- **Развитие Убежища (5 отсеков до 5 уровня)**: Медблок (регенерация), Торговый Отсек (скидки и тиры), Инженерный Цех (модификации), Гараж (скорость/таран, бронеджип) и Казарма со Складом (патроны и напарник). Спасённый **Сержант Шрам сражается рядом с игроком**.
- **Спецоперации и события**: зачистка баз, охота на командиров, освобождение пленных, охрана караванов, поиск редкого оружия в спецконтейнерах и **штурмы Убежища**. Дерево навыков из 9 перков, 17 достижений, 5 секретных бункеров с модулями.
- **Техника**: отдельные прозрачные PNG-игровые объекты и 6-кадровые спрайт-листы, AABB-коллизии, O(1) сетка пропов, лимиты частиц по качеству графики, полная работа офлайн и автосохранение спасённых, базы, mods, боссов и арсенала.

## 🚀 Локальный запуск и проверка

```bash
npm install
npm run build:web   # генерация спрайтов/иконок + 10 автотестов движка (10/10)
npm start           # веб-сервер превью на http://0.0.0.0:3000
```

Управление: виртуальный джойстик (полный наклон — бег), кнопки ОГОНЬ/ПРЫЖОК/Рывок/Граната/Аптечка/Перезарядка, навыки 1–3; клавиатура WASD + Shift, Пробел, K/L/G/R/Q/E/H.
